# Gestion-Citas-Medicas
Sistema de Gestión de Citas Médicas  Aplicación desarrollada para la materia Programación II, que permite a los pacientes agendar, modificar y cancelar citas médicas de manera eficiente. El sistema administra horarios, disponibilidad y especialidades médicas, facilitando la organización y control de las consultas.
